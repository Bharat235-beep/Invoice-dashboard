# Invoice Dashboard — Frontend

A React dashboard that displays invoices generated by the [invoice automation backend](https://github.com/Bharat235-beep/Invoice-generation-backend), with a live demo feature for sending a sample invoice to any email address.

**Live app:** https://invoice-dashboard-sepia-eta.vercel.app
**Backend API:** https://invoice-generation-backend.onrender.com

> The backend is on Render's free tier and spins down after inactivity — the first data load after idle time may take up to a minute.

## What it does

- Fetches invoice records from the backend's `/api/invoices` route and displays them in a table: order number, customer, total, email delivery status, and date
- Shows summary figures (total invoices, total invoiced, sent/failed counts) computed from the fetched data
- Provides a download link per invoice that streams a freshly generated PDF from the backend, rather than a stored file
- Includes a "try it yourself" section where a visitor can enter their own email and receive a sample generated invoice, rate-limited on the backend to prevent abuse
- Supports light and dark mode via `prefers-color-scheme`, and reflows into a stacked card layout on small screens instead of a horizontally-scrolling table

## Tech stack

- **React + Vite**
- **Plain CSS with custom properties** for theming — no CSS framework, since the goal was a specific, non-default visual identity (a warm, ledger/receipt-style palette using Fraunces for numbers/headings and IBM Plex Sans for body text) rather than a generic component-library look

## Environment variables

```
VITE_API_BASE=
```
Set to the backend's base URL — `http://localhost:3000` locally, or the deployed Render URL in production. Vite only exposes variables prefixed with `VITE_` to client-side code.

## Running locally

```bash
npm install
# add a .env file with VITE_API_BASE pointing at your running backend
npm run dev
```
